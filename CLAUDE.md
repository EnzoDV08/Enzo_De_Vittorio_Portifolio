# CLAUDE.md

Enzo De Vittorio's portfolio. Static, prerendered React site deployed to Firebase Hosting.

## Commands

- `npm run dev` — dev server (Vite, port 5173)
- `npm run build` — `react-router build` (prerenders every route into `build/client`) then `scripts/postbuild.mjs` (404 page, sitemap, robots, OG images)
- `npm run preview` — `scripts/preview.mjs`, a tiny static server that mimics Firebase (cleanUrls, no trailing slash, 404.html)
- `npm run typecheck && npm run lint && npm run build` — must all pass with zero errors/warnings before any commit
- `npm run images` — `scripts/optimize-images.mjs`: `_originals/<slug>/*` → `app/assets/projects/<slug>/*` (max 2400px masters)
- `npm run shots` — `scripts/shots.mjs`: Playwright screenshots of every route at 390/768/1440/1920 into `.shots/`

## Stack

- React 19, TypeScript strict (`noUncheckedIndexedAccess` on)
- React Router v7 **framework mode**, `ssr: false` + `prerender` (see `react-router.config.ts`). Routes are declared in `app/routes.ts`. No loaders — content is imported statically from `app/content`, so client navigation never fetches data files.
- Vite 8, Tailwind CSS v4 via `@tailwindcss/vite`. Design tokens live in `@theme` in `app/styles/app.css`.
- GSAP (core, ScrollTrigger, SplitText) + `@gsap/react` `useGSAP`; Lenis smooth scroll driven by GSAP's ticker.
- `vite-imagetools` turns project images into AVIF/WebP `srcset`s (see `app/lib/images.ts`).
- Fonts self-hosted via Fontsource (Geist, Geist Mono, Instrument Serif).

## Layout

```
app/
  content/      single source of truth for all copy and data (site, projects, experience, …)
  components/   UI primitives (ui/), layout (layout/), motion (motion/), page sections (sections/)
  lib/          hooks and helpers (useReducedMotion, gsap setup, images, seo)
  routes/       one file per route
  styles/       app.css — tokens and global styles
  assets/       optimized image masters (generated by `npm run images`, committed)
scripts/        build-time node scripts
_originals/     full-size source images (gitignored)
```

## Conventions

- Path alias `~/` → `app/`.
- **No copy inside components.** Text, links and data come from `app/content/*`.
- **Never invent facts.** Missing content is a `todo("…")` value from `app/content/todo.ts` and must also be listed in `CONTENT_TODO.md`. Components check `isTodo()` and render a visible marker or hide the element — never a broken link.
- Every animation goes through `useReducedMotion()`; with reduced motion, content is simply visible. Never hide content with CSS that only JS reveals unless the reduced-motion path also reveals it.
- GSAP plugins are registered once in `app/lib/gsap.ts` (client only). Use `useGSAP` with a scope so ScrollTriggers die with the component.
- Hover-only styles go inside `@media (hover: hover)` (Tailwind `hover:` variant already does this in v4).
- Full-height sections use `svh`/`dvh`, never `vh`.
- Focus ring: 2px accent, 2px offset — do not remove outlines.
- Never push to `main`; it auto-deploys the live site.
